# E-Commerce Store 

We are starting this as POC for SpiceMart, but we will be extending this to all other Stores. E-Commerce application for a local store, with a simple feature set based on the needs provided by the merchant
We provide simple features and cost-effective solutions for Merchants through the project. 

The following are deliverables for Merchants: 
> White-labeled web app

> White-labeled Android App

> White-labeled iOS app 


## Minimum requirements from Merchant: 
Google Account (Free account) or Google Workspace account.
